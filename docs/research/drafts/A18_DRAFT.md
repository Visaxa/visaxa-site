# How to Pressure-Test Salon Software Claims Before You Buy

I thought an official answer would settle it.

We had one requirement that mattered enough to affect the purchase. The vendor's page said the capability was included. The demo looked smooth. Several reviews sounded reassuring.

Then I tried to write the decision beside the evidence. The sentence “included” no longer felt complete. Included in which plan? For which role? Under what configuration? Would it produce the result our salon needed, or only something that looked similar in a demonstration?

That changed the question from “Do I trust this vendor?” to “What would make this particular claim safe to rely on?”
